# Copying a Course

In Zephyr, you can copy a course and its assignments over to a new course.

1. Navigate to the Courses table in the Management screen on Zephyr
2. Click the Options Cog on the Course you would like to copy
3. Click “Create Copy”
4. Change necessary Course information for the new course
   1. Name
   2. Start Date
   3. End Date
   4. etc.
5. **If there were assignments associated with the course** you copied from, a **Copy Assignments** window will appear
6. The table lists each **assignment** as a row and preloads the data from the assignments that belonged to the course from which you just made a copy. You will need to update the following at a minimum:
   1. **Due Date**
   2. **Start Date**
   3. **End Date**
7. Once all assignments have "Ready" as their status, the Submit button will become clickable
8. Click Submit
